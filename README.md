# Hackathon26
Aiden, Mithun, Ian

This project contains a small browser-based Pac-Man clone made with HTML, CSS, and JavaScript.

To play:
- Open `index.html` directly in a browser, or
- Run `python -m http.server 8000` in the project root and visit `http://localhost:8000`

Controls:
- Arrow keys or WASD to move
- Eat pellets, avoid ghosts, and collect power pellets to chase them down
